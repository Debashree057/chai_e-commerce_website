# 🍵 Chai E-Commerce Website

An online platform dedicated to bringing authentic chai experiences to customers. This project showcases a modern e-commerce website where users can browse, order, and learn about different varieties of chai.

## ✨ Features
- Product catalog with chai varieties (Masala, Green, Herbal, etc.)
- Shopping cart and checkout flow
- User authentication (login/signup)
- Order history and tracking
- Responsive design for mobile and desktop
- Admin panel for managing products and orders

## 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript (React optional)
- Backend: Node.js / Express (or Django/Flask if Python-based)
